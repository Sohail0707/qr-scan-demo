1. Scan a code

Each QR holds only a short address on this domain, for example /q/TA. A 302 redirect sends it to the scan page.

Also try /q/ta (lowercase) and /q/ZZ (unknown code).

How the redirect works

The printed code never points at a video or a page. It points at /q/TA, and one line in Netlify's _redirects file decides where that goes today:

/q/TA    /scan/test-a?src=qr    302
/q/ta    /scan/test-a?src=qr    302
/q/*     /?missing=1            302
/scan/*  /scan.html             200

Why 302 and not 301

A 301 means "moved forever", and browsers remember it. If you later change the destination, phones that scanned before keep going to the old one. A 302 is checked fresh every time, so the destination can change for years without reprinting.

Why the last two lines

/q/* catches any unknown code and sends it to the hub instead of a 404. /scan/* is a rewrite (status 200): every product uses one template, and the address stays clean.

The QR itself

Error correction Q lets about a quarter of the code be damaged and still scan. A short address keeps the grid small, so it scans reliably even when printed around 2 cm. The card above shows the grid size for this demo's address; a short custom domain like druglab118.com/q/DD fits version 3 (29 by 29 modules). It needs a 4-module white margin. Downloads are vector SVG, so printers can scale them without blur.
